Retriever bridge

For when Yahoo returns 429 to every server-side request.

Yahoo's chart endpoint sends no CORS headers, so this page cannot fetch it for you — the collector has to run on Yahoo's own origin. That is what the snippet below is for. It only reads public price data and posts it back to this local drop box; it sends nothing anywhere else.
  1. Open this Yahoo chart URL in a new tab.
  2. Open the browser console there — ⌥⌘J on macOS, Ctrl+Shift+J on Windows. If it asks you to type allow pasting first, do that.
  3. Paste the snippet below, press Enter, and wait. Progress prints in the console.
  4. When it finishes, the tab navigates here and shows a confirmation.
  5. Back in the terminal: python3 retriever/build_from_raw.py
